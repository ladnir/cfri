# RFC Multi-Layer Flag Transition Theorem Target

Scope: original non-systematic RFC distance certificate.

Status: theorem target with the conditioning proposition and coarse ambient lift lemma written.
This is the shared object that should replace separate ad hoc handling of the decomposable
marked-line row and the `theta_2=-1` kernel-chain row.

## State

For depth `h`, define:

```text
F_h((t_0,z_0), ..., (t_m,z_m))
```

as the first moment of flags:

```text
V_0 >= V_1 >= ... >= V_m,
dim V_i = t_i,
|Z(V_i)| >= z_i,
z_0 <= z_1 <= ... <= z_m.
```

The final distance event is:

```text
F_d((1,k+e)).
```

The recurrence must count one child flag over one shared child-code instance. It must never replace
a joint event by a product of child moments.

For proof bookkeeping it is useful to count exact witness zero sets. A witness for a flag is a
nested sequence:

```text
B_0 subset B_1 subset ... subset B_m,
|B_i| = z_i,
V_i vanishes on B_i.
```

Counting exact witnesses is an upper bound for the at-least event because every larger zero set
contains such a witness. The nesting is not cosmetic: it records the implication
`V_i <= V_{i-1} => Z(V_{i-1}) subset Z(V_i)` and prevents incompatible split choices from being
counted as one parent flag.

## One-Step Transition

For each active parent layer `V_i`, split the zero request into:

```text
P_i = paired child coordinates,
S_i = singleton child coordinates,
A_i = exact visible support inside S_i,
tau_i = visible quotient dimension on S_i,
K_i = ker(V_i -> visible singleton image).
```

The child objects generated by this layer are:

```text
pi(K_i) <= pi(V_i).
```

with zero budgets:

```text
z(pi(V_i)) >= |P_i| + |S_i| - |A_i|,
z(pi(K_i)) >= |P_i| + |S_i|.
```

The child state is the chain obtained by inserting all generated kernel children into the projected
parent chain:

```text
pi(V_0) >= pi(K_0) >= pi(V_1) >= pi(K_1) >= ...
```

then deleting repeated or zero-dimensional layers and merging identical dimension/zero-budget
requirements by keeping the strongest zero budget.

For nested witness sets the split data must be compatible layer-by-layer:

```text
P_i union S_i maps to B_i,
B_i subset B_j for i < j,
A_i subset S_i.
```

The compatibility condition is a source of free savings, so a safe proof may discard it and
overcount. A tight certificate should keep it at least for the rows listed below, because those are
the rows where the current scalar recurrence spends most of the slack.

The theorem must bound:

```text
F_h(parent flag)
  <= sum over split/support/local profiles
       Split
       * Local
       * Lift
       * F_{h-1}(merged child flag).
```

## Atomic Profiles And Safe Transition Proposition

Fix an atomic transition profile `Phi`. It includes:

```text
1. the nested witness zero sets B_i and their paired/singleton split P_i,S_i;
2. the exact visible supports A_i subset S_i;
3. the active parent-layer labels and dimensions t_i,tau_i,kappa_i;
4. the local root-line or quotient-incidence stratum used by each active layer;
5. the merged child flag shape U_0 >= ... >= U_r;
6. labels alpha(i), beta(i) with
      pi(V_i) = U_alpha(i),
      pi(K_i) = U_beta(i),
   after deleting repeated layers and keeping the strongest zero budget.
```

If the certificate groups many atomic profiles into one shape profile, the grouped recurrence must
multiply by the number of atomic profiles in the group. The proposition below is stated for atomic
profiles so that split multiplicity is not hidden inside the word `Lift`.

The merged child flag shape is:

```text
U_0 >= U_1 >= ... >= U_r,
dim U_j = u_j,
|Z(U_j)| >= y_j.
```

Let `Child(Phi)` be the set of child flags of this labeled shape. For a fixed child flag `U_*`, let
`Lift(Phi,U_*)` be the current-layer expected number, over the root challenges at this fold, of
parent flags, nested zero witnesses, local quotients, and root-line/quotient-incidence choices that:

```text
1. realize the atomic profile Phi;
2. map to the fixed child flag U_* by the labels alpha,beta;
3. satisfy the projection/kernel dimension constraints in Phi;
4. satisfy the local exact-support and root-compatibility conditions.
```

The child zero event itself is not included in `Lift`; it is the indicator in the child moment.
With this convention:

```text
Contribution_h(Phi)
  <= E_child sum_{U_* in Child(Phi)}
       1[U_* has the required zeros] * Lift(Phi,U_*).
```

Consequently, any uniform upper bound `Lift(Phi,U_*) <= L(Phi)` gives:

```text
Contribution_h(Phi)
  <= L(Phi) * F_{h-1}((u_0,y_0), ..., (u_r,y_r)).
```

If the best lift bound depends on geometric data of the child flag and not only on its shape, the
same conditioning gives a weighted child moment instead:

```text
Contribution_h(Phi)
  <= E_child sum_{U_* in Child(Phi)}
       1[U_* has the required zeros] * L(Phi,U_*).
```

The certificate can then either prove a uniform bound for `L(Phi,U_*)` on the row in question or
add the needed geometric datum to the flag state.

This is the proof-safe replacement for multiplying separate child moments. The proof is just
conditioning: expose the entire depth-`h-1` child code, enumerate actual child flags in that one
code, and then expose only the current-layer roots and parent lifts.

### Single-Layer Gaussian Lift Lemma

Fix one active parent layer with:

```text
K = ker(W -> singleton visible image),
dim W = t,
dim K = kappa,
tau = t - kappa.
```

Fix child subspaces:

```text
L <= V,
dim L = r_K,
dim V = r_V,
```

and require only the containments:

```text
pi(K) <= L,
pi(W) <= V.
```

Then the number of possible pairs `K <= W` is at most:

```text
Gamma_q^2 q^{kappa(2r_K-kappa) + tau(2r_V-t)}.
```

Proof: since `pi(K) <= L`, the kernel lift lies in `L+L`, so:

```text
# choices for K <= L+L
  <= [2r_K choose kappa]_q
  <= Gamma_q q^{kappa(2r_K-kappa)}.
```

For fixed `K`, the quotient `W/K` is a `tau`-dimensional subspace of `(V+V)/K`, whose dimension is
at most `2r_V-kappa`. Thus:

```text
# choices for W/K
  <= [2r_V-kappa choose tau]_q
  <= Gamma_q q^{tau(2r_V-kappa-tau)}
   = Gamma_q q^{tau(2r_V-t)}.
```

Multiplying gives the claim. Exact equalities such as `pi(K)=L` or `pi(W)=V`, nesting with other
parent layers, singleton root compatibility, and exact visible support can only reduce this count;
discarding them is a safe upper bound. The current-layer root law is accounted for in the local
profile factor, not in this purely linear-algebraic lift count.

### Coarse Ambient Multi-Layer Lift Bound

For each active parent layer, assume the two-layer lift hypotheses hold:

```text
K_i = ker(V_i -> singleton visible image),
dim K_i = kappa_i,
dim(V_i/K_i) = tau_i,
pi(K_i) = U_beta(i),
pi(V_i) = U_alpha(i),
dim U_beta(i) = r_{K,i},
dim U_alpha(i) = r_{V,i}.
```

Also assume the projection constraints are feasible:

```text
kappa_i <= 2 r_{K,i},
tau_i <= 2 r_{V,i} - kappa_i.
```

Let `I(Phi)` be the set of active layers in the atomic profile. A coarse ambient upper bound is
obtained by ignoring all cross-layer containment except the prescribed child flag and multiplying
the per-layer single-layer lift bounds:

```text
L_safe(Phi)
  <= Gamma_q^{2 |I(Phi)|}
     q^sum_{i in I(Phi)} [
               kappa_i(2 r_{K,i} - kappa_i)
             + tau_i(2 r_{V,i} - t_i)
       ],
```

where:

```text
t_i      = dim V_i,
tau_i   = dim visible singleton image of V_i,
kappa_i = t_i - tau_i,
r_{V,i} = dim pi(V_i),
r_{K,i} = dim pi(K_i).
```

This is not intended to be tight. Its proof is now formal: first fix every generated child subspace
in the merged chain, then choose each active parent layer independently using the single-layer
Gaussian lift lemma, and finally filter to the choices that form the required nested parent flag
and satisfy the local root/support profile. The independent choice can only overcount, so the bound
is safe once the projection/kernel feasibility constraints are verified for every active layer.
The certificate-critical work is to replace `L_safe` by sharper incidence-coupled lift bounds in
the few rows where `L_safe` consumes too much slack.

The displayed exponent is deliberately an ambient count in `pi(V_i)+pi(V_i)` modulo the chosen
kernel lift. It is larger than the quotient-incidence count in
`pi(V_i)/pi(K_i) + pi(V_i)/pi(K_i)`. A proof must use either this coarse ambient bound or the
sharper quotient bound with its separate kernel/fiber factor; it must not combine the savings from
both as if they were independent.

## Required Ingredients

### Exact Support Indexing

Visible supports are exact unmarked sets:

```text
A_i subset S_i.
```

Certificates such as marked cores, matched strides, component decompositions, or root-line
profiles may prove an upper bound for a fixed `A_i`, but they are not extra events after the
recurrence is already summing over exact supports.

### Local Tau-Two Incidence

For a tau-two quotient layer, apply the local theorem to the represented quotient:

```text
Q_i = pi(V_i) / pi(K_i)
```

on its exact visible support `A_i`, not to the full child code independently of the child flag.

The transition may always use the exact-support Grassmann cap:

```text
local_charge >= |A_i|.
```

When the layer-codimension theorem is available, the sharper local exponent is:

```text
theta_2(Q_i,A_i) = max_h(2h - 4 - gamma_h(Q_i,A_i)).
```

### Shared-Randomness-Safe Lifts

For a fixed merged child flag:

```text
U_0 >= U_1 >= ... >= U_r,
```

parent lifts are counted as one flag lying over this child flag. A safe upper bound is obtained by
choosing parent layers bottom-up, using Gaussian-binomial containment counts. A tighter proof should
intersect these ancestor choices with the same split/support/root constraints used by the local
terms.

The forbidden relaxation is:

```text
F_child(upper event) * F_child(lower event).
```

unless the two child events are over independent RFC code instances, which they are not inside one
recursion branch.

The first sharpening target is the quotient-lift version. For a parent layer with child quotient:

```text
Q_i = pi(V_i) / pi(K_i),
r_i = dim Q_i,
```

the parent quotient `V_i/K_i` is a `tau_i`-dimensional subspace of `Q_i + Q_i`, not of an unrelated
ambient child code. Therefore the local exact-support theorem and the quotient lift must be counted
inside the same represented quotient. For `tau_i=2`, the root-averaged quotient contribution should
be charged by:

```text
q^(4 r_i - 4 - |A_i|)
```

unconditionally from exact support, and by the sharper:

```text
q^theta_2(Q_i,A_i)
```

when the layer-codimension theorem is available. The recurrence should use the minimum of these
two charges, plus explicit polynomial factors.

## Corollary 1: Decomposable Marked-Line Row

For:

```text
tau = 2,
|A| = 2,
delta = 2,
comp = 2,
K = L = 0,
```

the quotient decomposes into two rank-one component lines. Let:

```text
z_V = |P| + |S| - |A| = |P| + |S| - 2
```

be the zero budget propagated to the child two-plane. The row specializes to the joint
marked-line/frame state:

```text
local_decomposable_row_contribution
  <= poly(N) * (q+1) * F_child((2,z_V), (1,z_V+1)).
```

This is not a product of two line moments. It is one two-layer flag event with a marked line.

### Local Marked-Component Certificate

In this quotient row:

```text
A = {j_1,j_2},
U_A = U_1 direct_sum U_2,
dim U_i = 1,
supp(U_i) = {j_i}.
```

Let `R` be the exact-support visible two-plane produced by the singleton equations after passing to
the child quotient `Q=pi(V)/pi(K)`. Since `delta=2` and `tau=2`, exact support and compatibility
force:

```text
R|_A = U_1 direct_sum U_2.
```

Thus `R` has two canonical component lines:

```text
R_1 = R cap {visible coordinate j_2 is zero},
R_2 = R cap {visible coordinate j_1 is zero}.
```

Because `K=L=0`, these quotient component lines lift to actual child lines `M_1,M_2 <= V`. The
common child two-plane `V` is already zero on:

```text
P union (S \ A),
```

so both lifted component lines are zero on this common set. In addition:

```text
M_1 is zero on j_2,
M_2 is zero on j_1.
```

Therefore every parent counted by this exact local row supplies at least one marked child line
with one extra zero beyond the common child two-plane budget. This is the marked line used below.

The root-to-line fiber is local to `A`. Under the uniform nonzero root law, each nonzero affine
root value has probability `(q-1)^-1`; passing through projective lines changes the count only by a
row constant depending on `|A|=2` and the determinant-`1` root parametrization. This constant is
absorbed into `C_row` and does not create another child moment.

### Joint Child-Flag Bound

Condition on the child code and on one child flag:

```text
M <= V,
dim V = 2,
dim M = 1,
|Z(V)| >= z_V,
|Z(M)| >= z_V+1.
```

By the local marked-component certificate, every parent in the row maps to at least one such
marked line. Choose one canonical marked line, for example the component line attached to the
smaller ordered coordinate of `A`; allowing either choice only changes `C_row` by a factor at most
two. The remaining component line, together with the orientation of the two visible coordinates,
is a frame choice inside `V`. For fixed `M <= V`, the number of possible completions is at most the
number of lines in a two-dimensional space:

```text
q + 1.
```

The lower flag layer records the extra zero forced on the marked component line:

```text
(2,z_V), (1,z_V+1).
```

All remaining split, coordinate-orientation, and exact-support choices are polynomial or explicit
binomial factors already outside the child moment. Root-line compatibility is local to the two
visible coordinates; after the two component lines and their orientation are fixed, it contributes
only the row's local finite constant.

Uniform frame-completion bound: for every actual child flag `M <= V`, the number of choices for
the second component line is at most:

```text
# {lines N <= V} = q + 1.
```

If the row requires `N != M`, this only decreases the count. The two possible assignments of the
visible coordinates to `(M,N)` and the finite root-to-line fiber are row constants. Thus the
ordinary child flag moment is valid for this row:

```text
Contribution <= Split * C_row * (q+1) * F_child((2,z_V),(1,z_V+1)).
```

This closes the child-randomness issue for the decomposable boundary row, modulo the explicit
finite row constant `C_row`. If a future implementation uses a broader contained-support count
instead of exact-support inversion, the certificate above no longer applies directly; it must first
separate the exact `|A|=2,delta=2,comp=2` row from smaller-support or connected subprofiles.

## Corollary 2: theta_2=-1 Kernel Chains

For the connected first-drop layer:

```text
first-drop contribution = -1,
a >= 5,
local_charge >= 9,
```

The full-row statement `theta_2 <= -1` is conditional until the `h=delta` full-kernel/component
endpoint is proved for the same support row.

Outer-child chains are controlled by zero-budget burn. If the recurrence follows the kernel child,
the theorem promotes the child state:

```text
L <= V
```

to:

```text
M <= U <= V'
```

when `L` itself takes a first-drop row. Thus kernel chains are counted by a single nested flag
moment, not by multiplying an upper moment and a lower moment.

Proof route: condition on the child flag `L <= V`. If the next transition follows `L`, expose the
grandchild code once and insert both descendants into the same flag:

```text
M = pi(ker(L -> visible image)) <= U = pi(L) <= V' = pi(V).
```

The kernel budget is stronger by exactly the visible support size:

```text
z_L - z_V = |A|.
```

For connected first-drop rows `|A| >= 5`, so every consecutive kernel-following transition adds a
new lower flag layer with at least five extra zero requests. The remaining proof obligation is to
show that the Gaussian lift and local tau-two incidence attached to those inserted layers are
dominated by this accumulated nested-flag zero budget before depth can grow with `d`.

As in the marked-line row, an ordinary nested flag moment is valid only after proving a uniform
bound over all child flags of the displayed dimensions and zero budgets. If the kernel-chain lift
depends on extra geometric data, that datum must either be charged uniformly or promoted into the
recurrence state.

The current truncation target is:

```text
length three is enough,
or length-four theta_2=-1 kernel chains are dominated by the extra local charge and zero-budget
constraints.
```

The ancestor-count mechanism for this target is deterministic. For fixed nested child zero
witnesses `B_i`, an ancestor layer above `V_{i+1}` must be chosen inside:

```text
H(B_i) = {messages vanishing on B_i},
```

not inside the whole child message space. Thus the ancestor factor is:

```text
GaussianBinomial(dim H(B_i)-t_{i+1}, t_i-t_{i+1})_q.
```

Large values of `dim H(B_i)` are themselves recursive rank-defect events and should be exposed as
extra flag layers. This is the flag-gap route to proving that long kernel chains do not require an
independent child moment or unbounded flag length.

The transition rule is:

```text
D_i := dim H(B_i).
```

Normal branch. If `D_i` is close to the shortened MDS value, the ancestor contribution is the
deterministic exponent:

```text
E_anc,i = (t_i-t_{i+1})(D_i-t_i),
```

and the chain is acceptable only when the sum of these exponents, plus split and local constants,
is dominated by the local kernel-chain charge.

Defect branch. If `D_i` is too large for the normal inequality, insert the canonical child
shortened-kernel rank event:

```text
R_{h-1}(D_i, |B_i|) := Pr_child[dim H(B_i) >= D_i],
```

The usual rank-tail expression:

```text
D_i(|B_i|-k_child+D_i)
```

is a diagnostic for the expected cost of this inserted event, not a replacement for it. The proof
must derive that exponent from the child rank recurrence or keep the event explicitly in the
recurrence.

This gives the intended no-cycle principle: every failed normal lift exposes a strictly larger
child shortened ambient event at the same child randomness, and that exposed event is bounded by
the same finite-replica recurrence rather than by an informal independence heuristic.

### Deterministic Defect Exposure Lemma

Fix the child code and a child zero witness `B` of size `z`. Let:

```text
H(B) = {messages whose child codeword vanishes on B},
D    = dim H(B).
```

Then `H(B)` itself is a `D`-dimensional child message subspace with at least `z` zero coordinates.
However, for defect routing the object to charge is the canonical subspace `H(B)`, not the set of
all `D`-dimensional subspaces contained in it. Therefore every transition that depends on the event
`dim H(B) >= D` should insert the rank event:

```text
R_h(D,z;B) = 1[dim H(B) >= D].
```

For nested witnesses:

```text
B_0 subset B_1 subset ... subset B_r,
```

the exposed shortened ambients form the reverse nested flag:

```text
H(B_0) superset H(B_1) superset ... superset H(B_r).
```

Therefore defect exposure is deterministic after conditioning on the child code; it does not use
any independence between the parent lift and the child event. The only multiplicity cost is the
finite witness/state count already present in the multi-layer flag recurrence.

Proof. The equations defining zeroes on `B` are homogeneous linear equations in the child message
space, so `H(B)` is a linear subspace. Every vector in `H(B)` vanishes on `B`, giving the zero
budget. If `B_i subset B_j`, then the equations for `B_j` include the equations for `B_i`, giving
the displayed nesting. This proves the exposure map.

### Canonical Rank-Defect Target

For a child code with message dimension `k`, the exposed nested shortened-kernel event is:

```text
dim H(B_i) >= D_i,
B_0 subset B_1 subset ... subset B_m,
|B_i| = z_i,
z_0 <= z_1 <= ... <= z_m
```

with the deterministic reverse nesting:

```text
H(B_0) superset H(B_1) superset ... superset H(B_m).
```

The random-linear benchmark exponent is still:

```text
Def((D_i,z_i)_i)
  = [z_0 D_0 + sum_{i=1}^m (z_i-z_{i-1})D_i]
    - [sum_{i=0}^m (D_i-D_{i+1})(k-D_i)],
D_{m+1}=0.
```

The first bracket is the number of zero equations for a generic linear code: new zero coordinates
added at level `i` need only vanish on `W_i`. The second bracket is the Grassmann dimension of the
nested witness subspace that certifies the rank event. For one exposed layer this reduces to:

```text
Def(D,z) = Dz - D(k-D) = D(z-k+D).
```

This is the rank-defect codimension used by the normal-slice diagnostics. The proof goal is to show
that the RFC shortened-kernel rank recurrence gives at least this exponent, up to explicit
polynomial/state-count constants, for the exposed canonical events created by defect routing.

Important correction. A raw flag moment:

```text
F_h((D,z))
```

counts every `D`-dimensional subspace inside `H(B)`. That is too loose for defect routing, because
the ancestor part of the kernel-chain proof already separately counts the flags chosen inside
`H(B)` by Gaussian factors. The defect event must charge the probability that the canonical
shortened ambient is large. The deterministic checker:

```text
scripts/rfc_distance_analysis/rfc_defect_conservation.py
```

exhibits this distinction: the naive fixed-witness flag-moment induction has large negative slack
on the exposed toy event `k=32, D=12, z=21`. The intended rank event must be analyzed by a
shortened-kernel rank recurrence, not by counting all witness subspaces.

### Shortened-Kernel Rank Recurrence Target

Define the fixed-witness rank event:

```text
R_h(D,B) = 1[dim H_h(B) >= D],
|B| = z,
rho_h(D,z) = -log_q Pr[R_h(D,B)=1] for the worst fixed B of size z.
```

The target is not automatically the generic value `D(z-k_h+D)`. RFC has exact paired compression.
If `B` consists only of paired requests over a child witness `P`, then the determinant-`1` fold is
invertible on each pair and:

```text
H_h(B) = H_{h-1}(P) direct_sum H_{h-1}(P).
```

Therefore:

```text
rho_h(D, 2p) = rho_{h-1}(ceil(D/2), p)
```

up to exact parity/endpoint conventions. This is the correct behavior that the raw flag moment
misses.

For a general fixed parent witness with:

```text
z = 2p + s,
```

paired requests first restrict to:

```text
H_{h-1}(P) direct_sum H_{h-1}(P),
```

and the `s` singleton equations impose root-dependent linear constraints on that canonical
ambient. The rank recurrence must sum over the dimension `D_P=dim H_{h-1}(P)` and local singleton
rank-drop profiles, then charge:

```text
rho_{h-1}(D_P,p) + local_singleton_rank_cost(D_P,D,s,profile).
```

The generic expression `D(z-k_h+D)` remains a calibration target. For the certificate, the actual
requirement is weaker and more concrete: the computed RFC rank cost `rho_h(D,z)`, together with
the local first-drop charges, must dominate the shortened-ancestor exponents on the finite set of
exposed theta-chain slices.

Current diagnostic status. The optimistic script:

```text
scripts/rfc_distance_analysis/rfc_shortened_rank_recurrence.py
```

shows that paired-spine cascades can make `rho_h(D,z)` far smaller than the generic value. For
example, the constrained toy split:

```text
h=5, k=32, D=12, z=21, p=10, s=1
```

has optimistic cost `1`, through a depth-one root-line collision lifted by paired compression. For
the observed-style `h=4,k=16,z=21` defects, the same diagnostic gives optimistic cost `2` for
`D=7` and `D=8`. Therefore the proof must either include these paired-spine rank events in the
nested kernel-chain state or prove that the local first-drop charges still dominate the ancestor
exponents after paying only this smaller `rho` cost.

The normal-slice checker now evaluates this combined margin directly. On the abstract
near-dimension toy:

```text
child_k=32, dims=(4,3,2,1), zeros=(21,26,31), b=1
```

generic routing gives margin `9`, but optimistic `rho` routing gives margin `-2`. This is a real
counter-signal to the generic-rank proof structure. On the observed level-local theta-chain
shapes, the same checker remains safe:

```text
child_k=8,  zeros=(21,26,31), b=4: rho-routed margin 13;
child_k=16, zeros=(101,106,111), b=4: cheap rho event impossible.
```

Thus the remaining proof should not try to prove all near-dimension chains. It should prove an
isolation lemma: dominant `theta_2=-1` rows in the RFC distance recurrence either have the observed
large zero-budget shape, or a near-dimension paired-spine branch pays another local
support/fiber/visibility charge before it can threaten the certificate.

The first isolation split is now concrete. A connected hard `theta_2=-1` row requires:

```text
s = a = 5
```

in the minimal no-residue case. The cheap paired-spine `rho` trace for the dangerous toy has no
such step:

```text
s=1, then s=8 with residue_if_a5=3, then all-paired / too small.
```

Therefore the theorem may treat exposed rank traces by two cases:

```text
hard theta-compatible trace step:
  s=5, keep the nested theta-chain flag and apply the normal/rho margin test;

non-hard paired-spine rank step:
  if s<5, it cannot host the connected a>=5 first-drop row;
  if s>5, any a=5 first-drop row leaves explicit outer residue s-5;
  if s=0, it is all-paired compression and does not create a new theta row.
```

More precisely, the atomic labels give `A subset S`, so `a<=s`; connected first-drop rows have
`a>=5`. Thus `s=5` forces `a=5`, while `s>5,a>5` is a larger-support tau-two row rather than the
minimal hard label. The larger-support case must be charged by its own local profile and flag gap

This does not yet prove the full recurrence, but it localizes the live proof obligation to minimal
