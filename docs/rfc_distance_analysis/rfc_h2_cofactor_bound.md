# RFC h=2 Cofactor Bound

This note gives the next local proof route after the `h=1` root-line drop bound.

## Setup

Let:

```text
M_A(ell): U_A + U_A -> F^A
```

be the root-line constraint matrix, and let:

```text
r = r_gen(A)
kappa_gen(A) = 2 dim(U_A) - r.
```

Choose an `r x r` submatrix `B(ell)` whose determinant is generically nonzero:

```text
f(ell) = det B(ell) != 0.
```

The `h=1` bound used:

```text
rank M_A(ell) <= r-1  =>  f(ell)=0.
```

For `h=2`, we use:

```text
rank M_A(ell) <= r-2  =>  rank B(ell) <= r-2.
```

Equivalently, all `(r-1) x (r-1)` cofactors of `B(ell)` vanish.

## Cofactor Bound

Let `I_2(B)` be the ideal generated by the `(r-1)`-minors of `B`.

If the cofactor variety has codimension at least `2` in `(P^1)^A`, then:

```text
# { ell : kappa_A(ell) >= kappa_gen(A)+2 }
  <= poly(a,r) * q^(a-2).
```

This controls the assignment count for the first `tau=2` case with:

```text
kappa_gen(A) = 0.
```

If `dim U_A <= 2`, this is already enough because every contributing assignment has
`kappa_A(ell)=2` and:

```text
GaussianBinomial(2,2)_q = 1.
```

For larger `dim U_A`, this is not by itself enough: assignments with `kappa>2` are weighted by

```text
GaussianBinomial(kappa,2)_q ~= q^(2kappa-4).
```

So the weighted `tau=2` recurrence needs either:

```text
1. higher-drop bounds for every kappa layer, or
2. a direct weighted cofactor/singularity bound.
```

The full-rank component terms are one such higher layer and must be split explicitly.

## Why Codimension 2 Is Plausible

The determinant `f` is multihomogeneous and row-linear in the root-line variables. In an affine
chart, its partial derivatives with respect to row variables are linear combinations of cofactors.
Thus:

```text
rank B <= r-2  =>  f = 0 and grad f = 0.
```

So the rank-two-drop locus is contained in the singular locus of the hypersurface `f=0`.

For a reduced hypersurface, the singular locus has codimension at least `2`. A codimension-one
singular locus can only come from repeated or common factors.

In matroid language, `f` is a signed basis polynomial for the generic row matroid seen by the chosen
minor. Basis polynomials factor over direct sums. Therefore:

```text
common cofactor factor  <=>  matroid decomposition / bottleneck.
```

This matches the observed profiles:

```text
component/direct-sum structure creates the large spikes;
after those are isolated, the h=2 layer should cost at least q^-2.
```

## Relation To Full-Rank Component Spike

The full-rank spike:

```text
kappa_A(ell) = dim U_A
```

is not controlled by the generic determinant singular-locus bound when it is better viewed as a
component diagonal-endomorphism family:

```text
# { ell : kappa_A(ell)=dim U_A } = (q+1)^comp(A).
```

This term should be split off before applying the cofactor bound. It is not an error term; it is a
real structural family already accounted for in:

```text
docs/rfc_distance_analysis/rfc_root_line_kernel_state.md
```

## Current Theorem Target

For every support `A`, decompose the generic row matroid of the chosen full-rank minor into connected
factors. Then:

```text
# { ell : kappa_A(ell) >= kappa_gen(A)+2 }
  <= component/full-rank terms
     + poly(a) * q^(a-2).
```

The proof obligation is now precise:

```text
show that after removing direct-sum/component factors,
the cofactor ideal has codimension at least 2.
```

This is a standard-looking matroid basis-polynomial statement, and it is the next local algebra
lemma needed for the `tau=2` recurrence.
