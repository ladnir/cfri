# RFC Kernel-Branch Nested Flag Recurrence

Scope: original non-systematic RFC distance proof.

Status: proof contract. This note defines the minimal nested-flag recurrence needed when a
`theta_2=-1` first-drop row recurses through the kernel child.

## Why The Two-Layer State Is Not Enough

For one parent subspace:

```text
W <= H_h,
dim W = t,
```

the flag recurrence creates:

```text
K = ker(W -> singleton visible image),
L = pi(K) <= V = pi(W).
```

The child zero budgets are:

```text
z_V = p + s - a,
z_L = p + s.
```

If the `theta_2=-1` first-drop row is followed through the outer child `V`, the zero-budget burn
lemma in `rfc_theta_minus_one_isolation_lemma.md` controls the chain. If it is followed through
the kernel child `L`, the next recurrence step is not independent of `V`; both live in the same
child code instance.

Therefore the proof-grade recurrence must count:

```text
L <= V
```

as one child event, and when `L` itself takes a kernel-producing transition, it must refine to:

```text
M <= U <= V'
```

in the grandchild code, where:

```text
U = pi(L),
M = pi(ker(L -> singleton visible image)),
V' = pi(V).
```

The invalid move would be:

```text
moment(V') * moment(M <= U).
```

That multiplies two first moments over the same grandchild randomness. The valid move is one
nested-flag moment:

```text
F_{h-2}((r_V,z_V'), (r_U,z_U), (r_M,z_M)).
```

## Nested Flag State

For a chain:

```text
V_0 >= V_1 >= ... >= V_m,
```

define:

```text
F_h((t_0,z_0), ..., (t_m,z_m))
```

to be the first moment, over RFC randomness through depth `h`, of flags satisfying:

```text
dim V_i = t_i,
|Z(V_i)| >= z_i,
t_0 >= t_1 >= ... >= t_m,
z_0 <= z_1 <= ... <= z_m.
```

The two-layer recurrence used so far is the case `m=1`. The kernel-branch first-drop chain needs
`m=2`.

## One-Step Nested Transition

Given a parent flag:

```text
W_0 >= W_1 >= ... >= W_m,
```

apply the one-step zero split to every active layer `W_i`. For each layer, choose:

```text
P_i, S_i, A_i subset S_i,
tau_i = dim visible singleton image of W_i,
K_i   = ker(W_i -> visible image on S_i).
```

The child subspaces generated by this layer are:

```text
V_i = pi(W_i),
L_i = pi(K_i) <= V_i.
```

The child zero budgets are:

```text
z(V_i) >= |P_i| + |S_i| - |A_i|,
z(L_i) >= |P_i| + |S_i|.
```

The proof state is the nested chain obtained by inserting all generated kernel children into the
ambient flag and then deleting duplicate dimensions. In the two-level kernel-following case:

```text
W_0 >= W_1
```

with the lower layer `W_1` active, the child chain is:

```text
pi(K_1) <= pi(W_1) <= pi(W_0).
```

This is the `M <= U <= V'` state.

## Lift Count

For a fixed child chain:

```text
M <= U <= V',
```

the lift count is bounded by choosing parent layers successively from bottom to top.

For the lower active layer `W_1`, with:

```text
dim W_1 = t_1,
tau_1 = 2,
kappa_1 = t_1 - 2,
dim M = r_M,
dim U = r_U,
```

the usual two-layer lift gives:

```text
Gamma_q^2 q^{kappa_1(2r_M-kappa_1) + 2(2r_U-t_1)}.
```

For the upper quotient `W_0/W_1`, choose the remaining parent directions inside `V'+V'` modulo
the already chosen `W_1`. A safe containment bound is:

```text
Gamma_q q^{(t_0-t_1)(2r_V-t_0)}
```

when the upper quotient is all-paired or otherwise has no active singleton quotient. More generally
the same local/lift factor used for an active quotient layer applies in the quotient chain
`V'/U`.

The important point is not the exact displayed safe exponent; it is the order of counting. We
choose a single nested parent flag lying over a single nested child flag. We do not choose an
upper child event and a lower child event independently.

## Kernel First-Drop Expansion

Suppose a top-level first-drop transition at depth `h` produces:

```text
L <= V
```

with child budgets:

```text
z_V = p + s - a,
z_L = p + s.
```

If the next first-drop row follows `L`, then expanding the child flag moment gives:

```text
F_{h-1}((r_V,z_V),(r_L,z_L))
  <= sum NestedTransition
       * F_{h-2}((r_V',z_V'),(r_U,z_U),(r_M,z_M)).
```

The lower active row contributes its own tau-two layer charge:

```text
q^{-local_charge(A_L)}
```

and its own exact-support split count. The nested grandchild state carries all three subspaces:

```text
M <= U <= V'.
```

Thus a kernel-following first-drop chain pays:

```text
top first-drop charge
+ lower first-drop charge
+ one nested-flag lift/split count
+ one nested child moment.
```

It does not pay:

```text
top charge + lower charge + moment(V') + moment(M<=U).
```

The latter is the product-of-first-moments error in another form.

## Safe Inner-First Relaxation

When the exact nested flag is too expensive to implement, there is a proof-safe relaxation that
still avoids multiplying child moments. Count the deepest child event first, then choose ancestors
as Gaussian superspaces.

For a two-layer flag:

```text
L <= V,
dim L = r_L,
dim V = r_V,
```

inside a child message space of dimension `k_child`, we have:

```text
F_h((r_V,z_V),(r_L,z_L))
  <= F_h((r_L,z_L))
     + log_q [k_child-r_L choose r_V-r_L]_q
  <= F_h((r_L,z_L))
     + (r_V-r_L)(k_child-r_V)
     + log_q Gamma_q.
```

This is the `inner-first` branch used by `rfc_flag_span_moment.py`.

For a three-layer flag:

```text
M <= U <= V',
dim M = r_M,
dim U = r_U,
dim V' = r_V,
```

the analogous bound is:

```text
F_h((r_V,z_V),(r_U,z_U),(r_M,z_M))
  <= F_h((r_M,z_M))
     + (r_U-r_M)(k_child-r_U)
     + (r_V-r_U)(k_child-r_V)
     + 2 log_q Gamma_q.
```

This relaxation is sometimes too loose for the final distance target because `k_child` can be
large near the top of the recursion. But it is a valid fallback and it proves that kernel-branch
chains are a state-counting/tightness problem, not a correctness problem. The exact nested-flag
recurrence is the tightening of this relaxation, replacing arbitrary ancestor superspaces with
ancestor subspaces that share the same fold split and local root constraints.

## Exponent Consequence For theta_2=-1

The local `theta_2=-1` row has:

```text
a >= 5,
delta = 3 in the minimal connected case,
local_charge = 4delta - 4 - theta_2 = 9.
```

A kernel-branch two-row chain therefore has two local charges of at least:

```text
9 + 9 = 18
```

q-dimensions before lift and split factors. Any apparent saving must come from nested flag
multiplicity. The recurrence above makes that multiplicity explicit as a flag-lift exponent and a
single grandchild nested-flag moment. There is no additional independent-copy entropy available
from multiplying child moments.

This is enough to keep the proof path viable: the remaining certificate question is finite and
state-based, not a new local algebra gap.

## Certificate Integration

The certificate driver should support three related states:

```text
one-layer:   F_h((t,z))
two-layer:   F_h((t0,z0),(t1,z1))
three-layer: F_h((t0,z0),(t1,z1),(t2,z2))
```

The three-layer state is only required when a marked `theta_2=-1` edge is followed through the
kernel child. If a later transition again follows the newest kernel child, the same rule extends
to a longer flag, but each extension adds:

```text
1. another explicit local first-drop charge;
2. another exact support set with a>=5;
3. one nested flag layer, not an independent child moment.
```

The number of possible flag dimension/zero-budget states is polynomial in `N` for fixed maximum
active flag length. The proof still needs a truncation lemma: either length three is enough for
the target certificate, or any length-four chain already has enough accumulated first-drop charge
and zero-budget burn to be dominated by the length-three bound.

