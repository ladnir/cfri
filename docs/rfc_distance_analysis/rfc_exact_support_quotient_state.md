# RFC Exact-Support Quotient State

Scope: original non-systematic RFC, determinant-1 fold with `T` uniform in `F^*`.

Status: theorem target. This note turns the current nested quotient diagnostics into a proof
contract. It is not yet a complete distance certificate.

## Purpose

The latest sparse pair-table diagnostics show that the old two-layer child flag is too small a
state. After the level-3 stress row `(4,7)>=(2,8)` is improved, the dominant depth-5 `z=34` trace
moves to scalar tau-two and tau-one quotient-incidence rows. The next recurrence must therefore
carry exact quotient data across nested parent layers, not only child containers.

The target is still the same first-moment event:

```text
B_d(1,k+e) <= 2^-lambda.
```

The new state should be understood as a refinement of the multi-layer flag state, not a different
proof architecture.

## Atomic State

For one fold, fix a parent flag:

```text
W_0 >= W_1 >= ... >= W_m.
```

For each active layer `i`, record exact witness data:

```text
B_i                 nested zero witness set;
P_i, S_i             paired and singleton child coordinates in B_i;
A_i subset S_i       exact visible singleton support;
tau_i                dim visible image on A_i;
K_i                  kernel of W_i -> visible singleton image;
V_i = pi(W_i)        child projection container;
L_i = pi(K_i)        child kernel container;
R_i = W_i/K_i        quotient datum, when tau_i > 0;
ell_i                root-line / root-plane compatibility labels on A_i.
```

The child zero requirements are:

```text
V_i zero on P_i union (S_i \ A_i),
L_i zero on P_i union S_i.
```

The nested witness sets satisfy:

```text
B_0 subset B_1 subset ... subset B_m.
```

This nesting is not bookkeeping fluff. It is what makes lower tau-zero rows eligible to sit inside
upper kernels and what determines when a lower quotient can be counted inside an upper quotient.

## Canonical Child Object

Expose the depth-`h-1` child code first. The projected containers generated by all active layers
form an inclusion diagram:

```text
V_i nodes,
L_i nodes,
containments inherited from W_j <= W_i and K_i <= W_i.
```

Equal-dimension containments are merged and keep the strongest zero budget. In particular:

```text
L_i <= V_i and dim L_i = dim V_i  =>  L_i = V_i.
```

A certificate state consists of:

```text
1. this child inclusion diagram with zero budgets;
2. exact split/support labels (P_i,S_i,A_i);
3. quotient nodes R_i and their root-compatibility strata;
4. compatibility labels describing how lower layers meet upper kernels.
```

The transition is evaluated by conditioning on the child code and summing actual child diagrams
once. There is no product of child moments over shared child randomness.

## Collapsed-Active Rerouting

Suppose a tau-positive row has:

```text
L_i <= V_i,
dim L_i = dim V_i,
A_i nonempty.
```

Then `L_i = V_i`. Since `L_i` is zero on `P_i union S_i`, the projected parent container `V_i` is
also zero on every coordinate in the claimed active support `A_i`.

Therefore the exact visible support was not actually `A_i`. A canonical exact-support recurrence
must reroute this witness to the row obtained by deleting the collapsed active coordinates from
`A_i` and recomputing `tau_i`. In particular, rows with collapsed active support can be excluded
from the tau-positive sum after exact-support canonicalization.

This justifies the scalar and pair-table diagnostic filter:

```text
--exclude-collapsed-active
```

provided the final proof states the canonical exact-support tie-breaking rule.

## Nested Quotient Counting

Let `W_j <= W_i`. There is always a map:

```text
W_j -> W_i/K_i.
```

Its kernel is:

```text
C_{j,i} = W_j cap K_i.
```

The lower quotient `W_j/K_j` injects into the upper quotient `W_i/K_i` only in the subcase:

```text
K_j = C_{j,i}.
```

More generally, if:

```text
K_j <= C_{j,i},
```

then only the quotient:

```text
W_j / C_{j,i}
```

is visible inside `W_i/K_i`; the residual:

```text
C_{j,i} / K_j
```

is consumed by the upper kernel and must be carried or charged separately. If `K_j` is not contained
in `K_i`, the lower quotient is not a subspace of the upper quotient at all, and an independent
quotient count is the safe fallback.

Thus the theorem-grade nested quotient state must record the compatibility type:

```text
upper-visible:    K_j = W_j cap K_i;
partly consumed: K_j < W_j cap K_i;
incompatible:    K_j not <= K_i.
```

In the upper-visible subcase, after the upper quotient datum is fixed, the lower tau-positive
quotient datum is counted as a `tau_j`-subspace inside a `tau_i`-space. Its Grassmann exponent is:

```text
tau_j (tau_i - tau_j).
```

This is the theorem target behind:

```text
--nested-quotient-mode inner-in-outer
```

The diagnostic is only proof-shaped for rows whose compatibility label is upper-visible. The final
recurrence must either carry this label or use the safe independent quotient count.

## Nested Parent-Subspace Counting

Once a parent layer `W_i` is fixed, a lower parent layer `W_j <= W_i` costs at most:

```text
[dim W_i choose dim W_j]_q
  <= Gamma_q q^(dim W_j (dim W_i - dim W_j)).
```

The lower layer's exact support, root compatibility, kernel, and child projection constraints are
then imposed conditionally and can only reduce the count.

This justifies replacing the remaining lower lift multiplicity by the nested Grassmann exponent
when the recurrence is explicitly summing nested parent flags rather than independent parent
layers. It is the proof target behind:

```text
--nested-subspace-mode inner-in-outer
```

Unlike nested quotient counting, this is a general parent-flag containment fact. The proof hazard
is accounting: the transition must choose the upper parent layer first and must not also multiply
by the lower row's old independent lift factor.

## Consumed-Kernel Containment

Let `W_j <= W_i`, and suppose the lower row has:

```text
tau_j = 0,
K_j = W_j.
```

If the exact witness nesting makes `W_j` vanish on the upper active singleton support `A_i`, then:

```text
W_j <= K_i.
```

This is the common case when `B_j` contains the upper witness coordinates `B_i`. In this subcase,
the upper kernel should be counted as a `kappa_i`-subspace containing the already fixed lower
subspace `W_j`, rather than as an arbitrary `kappa_i`-subspace of `L_i+L_i`.

If the ambient for the upper kernel has dimension `M = 2 dim L_i`, the exponent saving is:

```text
dim W_j * (M - kappa_i).
```

because:

```text
[M - dim W_j choose kappa_i - dim W_j]_q
  / [M choose kappa_i]_q
  ~= q^(-dim W_j (M - kappa_i)).
```

This is the theorem target behind:

```text
--consumed-kernel-mode tau0-inner-contained
```

The final recurrence must explicitly check the witness-nesting condition that places the lower
tau-zero layer inside the upper kernel. If that condition is absent, the safe fallback is the old
independent kernel count.

## Tau-Two Small-Support Rows

The current best non-tau-two-cover diagnostic still has the dominant row:

```text
p=8, s=2, a=2, tau=2,
K=0, outer_span=4,
local_charge=4, lift_qdim=12.
```

This is not fixed by the nested parent-flag rules. It is a local quotient-plane incidence problem:
for fixed child quotient ambient `Q = V/L`, exact support `A` of size `2`, and determinant-1
nonzero roots, count quotient planes in `Q+Q` compatible with the two root equations.

The existing universal exact-support cap:

```text
local_charge >= |A|
```

is too weak here. The final proof needs a small-support tau-two theorem that uses the represented
quotient matroid of `Q`, not only the ambient dimension. This is the next local blocker after the
nested state lemmas.

The latest decoded level-3 trace makes the shape sharper. For the stress state:

```text
(4,7) >= (2,8)
```

under collapsed-active rerouting and the nested quotient/subspace/consumed-kernel diagnostics, the
top pair row is:

```text
outer: p=2, s=3, a=2, tau=2, child=(4,2), z=3, charge=4, lift=12
inner: p=3, s=2, a=2, tau=1, child=(4,2), z=3, charge=2, lift=9
```

The trace columns report:

```text
outer kernel lift:                   4
outer quotient lift:                 8
inner kernel lift:                   3
inner quotient lift:                 6
inner nested quotient saving:        5
outer adjusted lift-minus-charge:    8
inner adjusted lift-minus-charge:    2
remaining quotient lifts:            outer 8, inner 1
```

Thus the nested line-in-plane rule is already doing its expected job: the lower tau-one quotient is
being counted as a line inside the upper tau-two quotient plane, costing one q-dimension instead of
a fresh six-dimensional quotient-line lift. The residual is mainly the upper represented
support-two quotient plane in its ambient quotient, not an unconsumed kernel fiber and not an
independent lower quotient-line count.

The next tau-two theorem should therefore be phrased as a represented support-two quotient-frame
bound. It must count the outer plane together with the root-compatible support-two frame and any
carried marked quotient lines as one quotient diagram. It may not delete quotient-plane incidence
altogether; the target is to replace the crude ambient plane count by the sharper count forced by
the exact two-root support and child zero containers.

## Tau-One Chain Rows

The anti-conservative sensitivity:

```text
--cover-lift-mode tau0tau2
```

still leaves the depth-5 `z=34` moment at:

```text
567.15416718 bits.
```

The dominant path is then:

```text
tau-one -> tau-one -> tau-zero.
```

The existing tau-one quotient-line lemma is locally safe, but the chain remains too expensive if
each level forgets the quotient line after one fold. The exact-support quotient state must carry
tau-one quotient lines recursively as event data, including their child container and any invisible
fiber dimension.

## Certificate Recurrence Shape

For an atomic exact-support quotient profile `Phi`, the theorem should prove:

```text
Contribution_h(Phi)
  <= Split(Phi)
     * RootIncidence(Phi)
     * NestedLift(Phi)
     * F_{h-1}(ChildDiagram(Phi), QuotientLabels(Phi)).
```

Here:

```text
Split(Phi)
  counts exact choices of paired/singleton/support sets;

RootIncidence(Phi)
  counts quotient lines/planes after determinant-1 nonzero roots;

NestedLift(Phi)
  counts only genuinely new parent-subspace, kernel, and quotient choices after all carried
  containments are conditioned on;

F_{h-1}
  is one joint child-code moment, never a product of moments.
```

The current scripts implement diagnostic shadows of `NestedLift(Phi)`. The missing theorem work is
to define `QuotientLabels(Phi)` precisely enough that every diagnostic saving is attached to a
valid compatibility label, and to prove the tau-two/tau-one root-incidence bounds for the remaining
dominant rows.
