# PA-Chain Closure Theorem Target

Status: proof-facing theorem extracted from the multi-mark closure diagnostic.

## Purpose

The low-rank flat endpoint needs to bound:

```text
C_d(p,a) = E[# {(P,A): |P|=p, |A|=a, A subset cl(P)}].
```

The main structured closure path is a PA chain: marked coordinates in `A` have their sibling in
`P`, so the PA projection lemma routes them to a child closure event. This note states the
deterministic implication and the lift count needed for a theorem-grade recurrence.

## Parent PA Setup

At a parent RFC fold, for each child coordinate `j`:

```text
L_j = (h_j, t_j h_j)
R_j = (h_j, (t_j+1) h_j).
```

Let `J` be the set of child positions carrying PA marks:

```text
for every j in J:
  one sibling is in P,
  the complementary sibling is in A.
```

Write:

```text
b = |J|.
```

Let `P_other` be all parent `P` columns except the `b` siblings paired with the marked coordinates
in `J`.

Let `Q` be the child projection support of `P_other`:

```text
Q = child positions touched by P_other.
```

More invariantly, let:

```text
U = span(P_other) <= H plus H
Proj(U) = pi_1(U) + pi_2(U) <= H.
```

## Deterministic Implication

If:

```text
A_J subset span(P_other plus PA-sibling-P columns),
```

then:

```text
h_j in Proj(U) for every j in J.
```

Equivalently:

```text
J subset cl_child(Q)
```

in the child matroid represented by the lower RFC code.

## Proof

Apply the one-coordinate PA projection lemma to each `j in J`.

For a fixed `j`, remove the P sibling at `j` from the core and call the remaining span `U_j`.
Since:

```text
P_other <= U_j
```

and all other PA sibling-P columns are also in the core, the one-coordinate lemma gives:

```text
h_j in pi_1(U_j)+pi_2(U_j).
```

But:

```text
pi_1(U_j)+pi_2(U_j) <= Proj(span(P_other plus PA sibling-P columns outside j)).
```

The projection span of the right-hand side is contained in the child span generated by:

```text
Q union (J\{j}).
```

Thus the sharpest direct conclusion is:

```text
h_j in span_child(Q union (J\{j})).
```

For all `j in J`, this implies:

```text
rank_child(Q union J) <= rank_child(Q) + b - 1
```

and if the dependency can be chosen uniformly after eliminating the other PA siblings, the desired
strong form is:

```text
J subset cl_child(Q).
```

The diagnostic used the strong form. The theorem must prove either the strong form or use the weak
rank-increment form with enough slack.

## Important Correction

For multiple PA marks, the one-coordinate lemma does **not** immediately prove:

```text
J subset cl_child(Q)
```

because the proof for one `j` may use the P siblings of the other marked coordinates. The safe
deterministic statement is:

```text
rank_child(Q union J) - rank_child(Q) <= b-1.
```

This is still useful. It means `b` PA closure marks produce at least one child marked-rank
dependency among the `b` projected marked child coordinates. Repeated elimination may recover a
chain of child closure events, but that requires an ordered/minimal-support argument.

## Lift Count For The Strong Recurrence

Assume a child closure event:

```text
(Q,J), |Q|=y, |J|=b, J subset cl_child(Q).
```

A parent lift to a PA configuration with total `p` P-columns and `a` A-columns can be counted by:

```text
2^b                         choose marked side over every j in J
2^y                         choose one P side over every q in Q
binom(2(n_child-b)-y, p-b-y) choose remaining P columns
```

If `a-b` marked columns are handled directly at the parent, multiply by:

```text
binom(n_parent, a-b) q^{-(a-b)(k_parent-p)}.
```

This is the lift bound implemented by:

```text
scripts/rfc_distance_analysis/rfc_closure_tail_multimark_recurrence.py
```

It is deliberately loose because it ignores disjointness refinements and allows direct marks to be
chosen anywhere.

## Consequence For The Proof

There are now two possible theorem routes.

### Strong PA-Closure Route

Prove:

```text
parent PA closure with b marks
  -> child closure event C_{d-1}(y,b).
```

Then the existing multi-mark diagnostic is directly theorem-shaped. Target runs pass with large
slack after residual repair.

### Weak Rank-Increment Route

Use the safe implication:

```text
rank_child(Q union J)-rank_child(Q) <= b-1.
```

This routes to a child marked incremental rank-tail event with one rank drop, not necessarily full
closure of all `b` marks. This is weaker but deterministic.

For the flat-excess endpoint `r=0`, a one-rank child drop among `b` PA marks may still be enough if
combined with:

```text
1. residual singleton-repair exponent q^{-(S-F)};
2. direct closure charges for marks not routed through PA;
3. iteration/minimal-support decomposition to peel one dependent mark at a time.
```

## Current Status

The one-mark PA case is proved by `rfc_pa_mixed_projection_lemma.md`.

For multiple PA marks, the strong recurrence used in the diagnostic has a hidden assumption:

```text
other PA sibling-P columns are not needed to prove each marked child lies in closure of Q.
```

The safe theorem is a rank-increment drop:

```text
rank(Q union J)-rank(Q) <= b-1.
```

Next proof work should decide whether the strong form is true after choosing a minimal PA witness,
or whether the recurrence should be rewritten around the weak rank-increment form.
