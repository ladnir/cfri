# Flat-Excess Charge Push

Goal: make the upgraded original-proof route concrete by charging positive flat excess through
marked incremental rank events.

## Algebraic Bridge

In the fixed-survivor proof, after top paired coordinates `P` are fixed, let:

```text
K_P = ker(child evaluation on P)
D   = dim K_P = k_child - rank(P).
```

For singleton child positions `T`, each singleton repair row restricts to a functional:

```text
ell_i in K_P^*.
```

For a subset `A subset T`, write:

```text
r(A) = rank{ell_i : i in A}.
```

But this rank is exactly:

```text
r(A) = rank(P union A) - rank(P).
```

Reason: the image of `A` restricted to `K_P` is the extra rank added by `A` after quotienting by
the span already generated by `P`.

Therefore a flat-excess witness:

```text
|A| - 2r(A) = F
```

with `r(A)=r` and `a=|A|=2r+F` is exactly the marked incremental rank event:

```text
rank(P union A) - rank(P) <= r.
```

This is the key reduction. Flat excess is not an abstract defect of the singleton repair matroid;
it is a marked child-code rank-tail event.

## Combined Exponent

For a fixed top profile `(P,T)`, let:

```text
t = |T|
S = t - 2D + 1
```

be the ideal singleton surplus repair exponent before flat-excess correction.

If a witness has:

```text
a = 2r + F,
rank increment <= r,
```

then the random-matrix marked-rank exponent is:

```text
(a-r)(D-r) = (r+F)(D-r).
```

The residual root-repair exponent after flat excess is:

```text
max(0, S-F).
```

So the combined exponent for this stratum is:

```text
Q(r,F) = (r+F)(D-r) + max(0,S-F).
```

For `F <= S`, write `h = D-r >= 1`. Then:

```text
Q(r,F)
  = (D-h+F)h + S-F
  = hD - h^2 + S + F(h-1).
```

The weakest high-rank case is `h=1`, i.e. `r=D-1`, giving:

```text
Q(D-1,F) = D - 1 + S.
```

The flat-excess loss `F` cancels exactly in this worst high-rank stratum.

For `F>S`, the residual repair exponent is zero, but the same `r=D-1` stratum gives:

```text
Q(D-1,F) = D - 1 + F,
```

which only increases with `F`.

Thus, under a marked-rank tail theorem, positive flat excess is not a local loss. It forces an
additional marked child-rank event whose q-exponent is at least about `D+S`.

## Original Broad Lemma

Let `P,A` be disjoint child coordinate sets with:

```text
|P|=p,
|A|=a,
rank(P)=p-u,
D = k_child - p + u.
```

For `a=2r+F` and `r<D`, prove a first-moment bound of the form:

```text
E[# marked pairs (P,A) with rank(P union A)-rank(P) <= r]
  <= poly(n,d,a) q^{-c_marked(a,r,D)}
     * entropy(P,A)
     * recursive paired-loss terms
```

where the target exponent is close to:

```text
c_marked(a,r,D) = (a-r)(D-r).
```

For the flat-excess charge, we do not need the full random exponent everywhere. It is enough to
prove that after entropy and recursion, the stratum contributes at most:

```text
2^{-lambda} q^{-(S-F)}
```

when multiplied by the residual repair failure probability. In the top stress profile, there is
huge slack.

This broad lemma has since been reduced in the endpoint regimes:

```text
high-rank endpoint:
  h=1 ordinary child line-zero event;

low-rank endpoint:
  r=0 closure-tail event A subset cl(P);

multi-PA closure:
  safe one-rank child drop, reduced by circuit union to one-mark closure.
```

## What Still Can Fail

This push rests on one serious assumption:

```text
RFC marked incremental rank tails behave at least qualitatively like random matrices,
up to recursive all-paired losses.
```

We already know the unmarked aggregate short-set tail is false as an abstraction. The marked
object fixes that specific overcount, but it still needs proof.

The remaining binary obstruction is therefore no longer "flat excess might cost F". It is:

```text
Can the closure-tail and subcode-zero endpoint recurrences be proved with controlled RFC
shape-recursive losses?
```

The all-mixed PA full-span reduction helps here because the scary mixed profile routes to a
deterministic two-copy span deficiency, which is exactly the kind of recursive marked event this
lemma is supposed to charge.
