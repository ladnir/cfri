# RFC No-Early-Gluing Lemma

This note isolates the algebraic obstruction that should complete exact stability.

## Setup

At a parent node, suppose both child messages are nonzero and exact:

```text
u = A x_0
v = A x_1.
```

Equality in the uncertainty proof forces:

```text
supp(u) = supp(v) = W'
```

and the parent output support contains exactly one sibling over each coordinate of `W'`.

For each `j in W'`, the parent local outputs are:

```text
y_{0,j} = (1-T_j) u_j + T_j v_j
y_{1,j} = -T_j u_j + (T_j+1) v_j.
```

To kill the left sibling:

```text
v_j / u_j = -(1-T_j)/T_j.
```

To kill the right sibling:

```text
v_j / u_j = T_j/(T_j+1).
```

The fresh variables `T_j` are independent across `j`.

## Lemma

If:

```text
|W'| > 1,
```

then the two-child equality branch cannot occur generically.

## Proof

Let `K` be the rational function field generated by all child-level challenges. The fresh parent
variables:

```text
T_j,  j in W'
```

are algebraically independent over `K`.

By the recursive exact-boundary statement for the child node, each child exact support/output pair
has a one-dimensional kernel line. Therefore, after choosing representatives of those two child
kernel lines, the child outputs on `W'` have the form:

```text
u_j = alpha U_j
v_j = beta  V_j
```

where:

```text
U_j, V_j in K^*
alpha, beta in K(T_j : j in W')^*
```

and only the single relative scalar:

```text
lambda = beta / alpha
```

is free at the parent level.

For each coordinate `j`, killing one parent sibling imposes:

```text
lambda = L_j(T_j) * U_j / V_j
```

where:

```text
L_j(T_j) in { -(1-T_j)/T_j,  T_j/(T_j+1) }.
```

Pick two distinct coordinates:

```text
j1 != j2 in W'.
```

Eliminating `lambda` gives:

```text
L_{j1}(T_{j1}) * U_{j1}/V_{j1}
  =
L_{j2}(T_{j2}) * U_{j2}/V_{j2}.
```

The factor:

```text
(U_{j1}/V_{j1}) / (U_{j2}/V_{j2})
```

lies in `K` and is independent of the fresh parent variables. Thus the equation would imply:

```text
L_{j1}(T_{j1}) = c L_{j2}(T_{j2})
```

for some `c in K^*`. This is impossible in the rational function field
`K(T_{j1},T_{j2})`, because `L_{j1}` is a nonconstant rational function of `T_{j1}` alone and
`L_{j2}` is a nonconstant rational function of the algebraically independent variable `T_{j2}`.

Therefore the simultaneous cancellations cannot hold as a rational identity.

This proves the no-early-gluing lemma.

Therefore any exact extremizer must use the one-child branch until:

```text
|W'| = 1.
```

This is exactly the node whose size equals the live support size `m`.

## Consequence

The equality recursion has forced form:

```text
1. descend through one child while the current node is larger than m;
2. once the live rows fill the current node, glue sibling child extremizers;
3. repeat the glue step recursively inside the selected output coordinate.
```

This yields:

```text
R = contiguous block of size m
W = stride class modulo m.
```

Together with the matched-kernel construction, this gives the exact stability theorem:

```text
dim ker(A[R, [k]\W]) =
  1 if (R,W) is matched,
  0 otherwise
```

at the exact boundary `|R||W|=k`.

This argument is local and independent of the rest of the distance counting machinery.
