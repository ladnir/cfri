# RFC Upper-Bound Recurrence State

Scope: original non-systematic RFC only. The systematic variants are out of scope for this note.

This note is the upper-bound/proof agent's current state proposal. It does not claim a proof. The
point is to make the missing recurrence state explicit enough that the proof and falsification
tracks can attack the same object.

## Current Diagnosis

The scalar span recurrences are losing the decisive information.

The bad pattern is:

```text
global child span dimension t is large,
but on a singleton block only tau dimensions are visible,
so t - tau directions are invisible on that block.
```

Those invisible directions are not free. If a parent subspace `W` is zero on a singleton coordinate
because the visible quotient vanished there, then the corresponding child directions vanish on both
child halves at that child coordinate. The kernel directions must therefore receive a recursive
common-zero charge.

The current coarse state `(span, z)` remembers `t` and total requested zeros, but forgets which
subspace directions gained those extra child zeros. That is why it can still produce pessimistic
traces after the impossible `tau=2, delta<2` branch was removed.

## One-Step Object

At one RFC fold, write the parent message space as:

```text
H_h = H_{h-1} + H_{h-1}.
```

For a subspace:

```text
W <= H_h,
dim W = t,
```

and a zero request set at this parent level, split child positions into:

```text
P = paired positions, both parent coordinates requested zero,
S = singleton positions, exactly one parent coordinate requested zero.
```

Let:

```text
p = |P|,
s = |S|,
z = 2p + s.
```

For singleton positions, let:

```text
ev_S : W -> C_{h-1}|_S + C_{h-1}|_S
R    = ev_S(W)
tau  = dim R.
```

Let:

```text
A = supp(R) subset S,
a = |A|,
I = S \ A,
K = ker(ev_S | W).
```

Then:

```text
dim K = t - tau.
```

Let `pi(W)` be the child span generated by all left and right child projections of vectors in `W`.
Likewise define `pi(K)`.

The key zero propagation is:

```text
pi(W) vanishes on P union I,
pi(K) vanishes on P union S.
```

So the child recursion must count a flag:

```text
pi(K) <= pi(W)
```

with two different zero budgets:

```text
z_pi(W) >= p + (s - a),
z_pi(K) >= p + s.
```

This is the first state that keeps the invisible directions honest.

## Candidate Recurrence State

The certificate state should count nested flags, not just one subspace.

Define:

```text
F_h((t_0,z_0), ..., (t_m,z_m))
```

as the q-exponent, plus separately tracked bit constants, for flags:

```text
V_0 >= V_1 >= ... >= V_m >= 0,
dim V_i = t_i,
common_zero_count(V_i) >= z_i.
```

The intended invariant is:

```text
t_0 > t_1 > ... > t_m >= 0,
z_0 <= z_1 <= ... <= z_m.
```

Deeper subspaces are smaller but have at least as many common zeros. A singleton block can then
move coordinates from `z_i` to `z_{i+1}` when the quotient `V_i / V_{i+1}` is visible but the
kernel `V_{i+1}` is invisible.

The starting first-moment event is the one-layer flag:

```text
F_d((1, k + e)).
```

In one step, a quotient layer:

```text
Q_i = V_i / V_{i+1},
tau_i = dim visible image on the singleton block,
```

pays the local compatible-visible-subspace factor for its exact support `A_i`, while the kernel
layer receives the additional child zero budget from `A_i`.

For the simplest two-layer transition `K <= W`, the shape is:

```text
B_h(t,z)
  <= sum_{p,s,a,tau,r0,r1}
       split_count(p,s,a)
       * local_h(A,tau)
       * lift_count(t,tau,r0,r1)
       * F_{h-1}((r1, p+s-a), (r0, p+s)).
```

Here:

```text
r1 = dim pi(W),
r0 = dim pi(K),
0 <= r0 <= 2(t - tau),
tau <= r1 <= 2t.
```

The exact formula has to sum over support matroid data, not just `a`:

```text
rank(A), comp(A), delta(A), g(A), theta_2(A).
```

The important point is that the singleton charge does not disappear into a scalar child state. It
creates a stricter zero budget on the kernel subspace.

Tau-2 correction: `g(A)` and `comp(A)` are not sufficient local state.  The endpoint charge must
use:

```text
theta_2(A) = max_h(2h - 4 - gamma_h(A)),
```

where `gamma_h(A)` is the codimension of the root-line layer
`{ell : dim K_A(ell) >= h}`.  The smallest concrete failure of the older shortcut is a connected
`a=5, delta=3, comp=1, g=1` exact support with a codimension-one `h=2` layer.

The next state issue is incidence/framing.  The parent quotient `W/K` is not just an abstract
visible subspace counted locally, and it is not just an abstract Gaussian lift into the child flag.
For tau-two layers, the recurrence must count the incidence:

```text
(L <= V, Q = W/K, A, h)
```

where `Q` maps into `V+V`, has visible singleton support `A`, and lies in the root-line layer
`X_h(A)`.  The depth-5 checkpoint exhibits a neutral branch with `local_charge=lift_qdim=12`, so a
proof cannot rely on a scalar leftover charge from that transition.

The coarse part of this incidence problem is now controlled for every tau-two exact-support
quotient branch: after the child flag and kernel are fixed, root averaging gives a universal
charge:

```text
local_charge >= |A|.
```

In the full-cover `K=L=0` subcase, if `P union S` is the whole child coordinate set, restriction
gives `V ~= V|_A` and:

```text
E_{V,A}(2) q^-|A| <= Gamma_q q^(4 dim(V)-4-|A|).
```

For the neutral trace this is `q^(12-59)`. The remaining recurrence issue is the sharper
layer/fiber accounting needed when `|A|` is small, not hidden large-support quotient lift.

The smallest small-support row is also not an indecomposable obstruction. For
`|A|=2,delta=2,comp=2,K=L=0`, the local exponent is neutral, but the exact-support quotient splits
into two rank-one components. The recurrence should route that contribution through a joint
marked-line/frame state:

```text
product_row_contribution
  <= poly(N) * (q+1) * F_child((2, outer_zeros), (1, outer_zeros + 1)).
```

The squared first-moment split is invalid because the two lines share the same child-code
randomness. The small-depth checkpoint must be rerun after a joint state is implemented.

## Local Lemmas Needed

### L0. Support-Containment Lemma

This is already available and should be treated as safe.

For `U <= F^S` and `A subset S`, if a compatible visible subspace has support contained in `A`,
then:

```text
R <= U_A + U_A,
U_A = {u in U : supp(u) subset A},
dim U_A = delta(A) = rank(S) - rank(S \ A).
```

This gives the ambient bound:

```text
# tau-subspaces with support contained in A
  <= GaussianBinomial(2 delta(A), tau)_q.
```

### L1. Tau-One Exact-Support Count

For `tau=1`, compatibility is automatic. The exact-support line count should be bounded by the
support-profile inversion of lines in `U_A + U_A`.

A usable exponent bound is:

```text
E_A(1) <= poly(a) q^(2 delta(A) - 1).
```

After root weighting:

```text
E_A(1) q^-a <= poly(a) q^(2 delta(A) - 1 - a).
```

For tightness, the recurrence should use the exact support-profile coefficient when available,
because this is one of the places where the `e=71` slack is small.

### L2. Tau-Two Layer Bound

For `tau=2`, the component-only theorem and the older generic/component maximum are false as
general local theorems. The corrected local object is the layer exponent:

```text
E_A(2) q^-a
  <= poly(a) q^theta_2(A),

theta_2(A) = max_h(2h - 4 - gamma_h(A)).
```

where:

```text
gamma_h(A) = codim { root lines ell : dim K_A(ell) >= h }
```

Also:

```text
delta(A) < 2  implies  E_A(2) = 0.
```

The connected `a=5, delta=3, comp=1, g=1` row shows why the shortcut fails: it has a
codimension-one `h=2` layer, giving `theta_2=-1` rather than the older `-2` prediction. That
local row is now accounted for by:

```text
docs/rfc_distance_analysis/rfc_g1_first_drop_endpoint_lemma.md
```

The live blocker is no longer this individual local algebra row. It is the global recurrence
question: can `theta_2=-1` first-drop rows chain through several levels without an additional
kernel/support charge? The current target state for that question is:

```text
docs/rfc_distance_analysis/rfc_theta_minus_one_chain_recurrence_target.md
```

### L3. Higher Tau Escape Hatch

The current proof should not depend on a broad unproved `tau>=3` theorem unless the recurrence
forces it.

Preferred path:

```text
first close a flag recurrence whose dominant traces only use tau=0,1,2.
```

If a legitimate upper-bound trace needs `tau>=3`, then we either need a higher-tau local incidence
theorem or a quotient-flag refinement that splits the visible quotient into one- and two-dimensional
layers without losing too much.

### L4. Kernel-Zero Propagation

This is the main global lemma.

In the one-step setup above:

```text
pi(W) vanishes on P union (S \ A),
pi(K) vanishes on P union S.
```

The proof is coordinatewise:

* paired coordinates invert the fold, so both child coordinates vanish for all of `W`;
* singleton coordinates outside `A` have zero visible projection for all of `W`, so both child
  coordinates vanish for all of `W`;
* kernel vectors are invisible on every singleton coordinate in `S`, so both child coordinates
  vanish for all of `K`.

This lemma is what prevents hidden kernel dimensions from floating through the recurrence for free.

### L5. Flag-Lift Count

Given a child flag:

```text
L <= V <= H_{h-1}
```

with dimensions:

```text
dim L = r0,
dim V = r1,
```

we need a bounded count of parent subspaces `W <= H_{h-1}+H_{h-1}` and kernels `K <= W` such that:

```text
pi(W) = V,
pi(K) = L,
dim W = t,
dim K = t - tau,
ev_S(W)/ev_S(K) has visible dimension tau.
```

The expected exponent should be a Gaussian flag/lift term depending only on small dimensions:

```text
O(t^2 + r1^2)
```

or a sharper explicit expression. This term is harmless if it stays polynomial in `N` and small
dimensions, but it must be included in the final bit slack. It is not safe to silently set it to
one.

The current precise target, including the Gaussian-binomial lift constant and exact-support
counting rule, is recorded in:

```text
docs/rfc_distance_analysis/rfc_upper_bound_flag_lemma_target.md
```

### L6. Split-Count Accounting

The q-exponent recurrence can hide binary combinatorial factors only if the final certificate
tracks them in bits.

At each level, split choices contribute:

```text
choose child positions for P, S, A,
choose singleton orientation,
choose support matroid profile,
finite GL_tau constants.
```

The current ideal certificate has only about `30` to `40` bits of meaningful slack at
`c=8,k=2048,q=2^128,e=71`, depending on which stress model is used. The recurrence cannot spend
large undocumented constants.

The multi-copy broad-family stress also shows that support-family multiplicities must be exact.
In particular, the `b=1` broad near-family must be counted by unmarked output supports, not by
marked `(core, extras)` certificates. See:

```text
docs/rfc_distance_analysis/rfc_upper_bound_response_to_multicopy.md
```

## Dominant Trace Hypothesis

For the target:

```text
c = 8,
k = 2048,
N = 16384,
q = 2^128,
e = 71,
z = k + e = 2119,
```

the expected dominant upper-bound trace is an all-paired or almost-all-paired spine.

The first compression is:

```text
depth 11: k=2048, z=2119, e=71
  all-paired child target roughly
depth 10: k=1024, z=1060, e=36
```

This matches the previous `e=71` versus `2*36=72` evidence. Continuing the same heuristic gives:

```text
depth  k     z       excess
11     2048  2119    71
10     1024  1060    36
9      512   530     18
8      256   265     9
7      128   133     5
6      64    67      3
5      32    34      2
```

This table is not a proof trace, because the child span dimension grows under repeated paired
compression. The flag recurrence must decide where this growth is paid.

My hypothesis is:

```text
1. the true dominant trace stays close to this paired-compression spine;
2. singleton blocks enter mainly to realize the final excess and support-profile entropy;
3. sustained tau=2 dense-support singleton layers are not dominant after kernel-zero propagation;
4. if a counterexample exists, it likely appears as a nested-kernel cascade riding this spine.
```

What the next diagnostic should test is not another scalar crossing. It should test whether the
two-layer state:

```text
F_{h-1}((r1, p+s-a), (r0, p+s))
```

already knocks down the depth-4 pessimistic trace. If it does not, either the statement needs more
slack or the state must allow a longer flag.

## Feedback For Lower-Bound Agent

Please attack the same state from below. The most useful falsification families are:

1. Nested-kernel cascades.

   Build supports where a visible quotient pays only `tau=1` or `tau=2` roots, while a large kernel
   repeatedly vanishes on the singleton support and survives through paired compression. If such
   cascades have high entropy, they are exactly the thing the proposed flag recurrence is trying to
   rule out.

2. All-paired spine plus late singleton burst.

   Start from the `71 -> 36 -> 18 -> 9 -> 5 -> 3 -> 2` compression table. Search for the level
   where a large singleton burst gives the best lower-bound expectation after accounting for child
   span growth.

3. Dense connected tau-two supports.

   Look for connected supports with `generic_kernel_dim g >= 2` where the generic endpoint
   dominates the component endpoint. These are the supports that killed the old component-only
   theorem. If they align recursively, the upper-bound recurrence may need more excess.

4. Multi-copy sparse-support correlation.

   The upper-bound state assumes child flags and root-line kernels can be counted by local
   matroid data plus recursive zero budgets. Try to find messages or two-dimensional subspaces that
   are sparse in two independent RFC copies more often than the product tail predicts.

5. Nonzero-root orientation effects.

   The proof model often counts all projective root lines and treats determinant-1 nonzero `T` as a
   constant-factor restriction. Check whether the excluded/duplicated lines systematically favor
   sparse families.

6. Broad one-copy near-extremizers with stride dimension.

   The existing wide stress model crosses between `e=70` and `e=71`. Try to turn the best modeled
   row into a recursively described family, not just a first-moment stress row.

## Questions For Integrator

1. Is the intended final certificate allowed to land at `e=72` if honest constants consume the
   remaining `e=71` slack, or is `e=71` the hard target?

2. What exact top-level moment should the certificate state use:

   ```text
   projective message lines,
   ordered nonzero messages,
   or ordered finite replicas followed by projectivization?
   ```

   The answer changes the finite `GL_tau` and lift constants.

3. Do we have a fixed formal statement of the determinant-1 fold matrix and the exact singleton
   root-line distribution for `T` uniform nonzero? The upper-bound proof needs the exact constant
   loss between actual roots and all projective lines.

4. Can we cap the upper-bound recurrence to `tau<=2` for the first certificate attempt, based on
   observed dominant traces? If not, we need either a higher-tau local theorem or a quotient-flag
   decomposition lemma.

5. Should the first executable recurrence count full flags, or only the two-layer state
   `K <= W`? The current recommendation is staged: keep the two-layer state as the broad
   checkpoint, but add the three-layer state for the specific case where a `theta_2=-1`
   first-drop row is followed through the kernel child. The recurrence contract for that case is
   `rfc_kernel_branch_nested_flag_recurrence.md`.

6. How much slack should be reserved for polynomial and orientation factors before calling a bound
   acceptable? My current recommendation is to require at least `20` bits of residual slack after
   all known constants, which may force checking both `e=71` and `e=72`.
