# RFC Exact Stability Theorem Draft

This note assembles the exact one-copy stability proof.

## Statement

Let `A_d` be one depth-`d` RFC parity transform over the rational function field generated by the
fold challenges. Let:

```text
k = 2^d.
```

For row support `R` and output support `W` satisfying:

```text
|R| |W| = k,
```

the exact-boundary kernel statement is:

```text
dim { x in F^R : supp(A_d x) subset W } =
  1  if (R,W) is a matched block/stride pair,
  0  otherwise.
```

A matched pair means that for `m=|R|`:

```text
m = 2^t,
R = { s m, s m + 1, ..., s m + m - 1 },
W = { r, r + m, r + 2m, ..., r + (k/m - 1)m }.
```

## Ingredients

The proof uses three facts.

1. **One-copy uncertainty.**

```text
wt(x) wt(A_d x) >= k.
```

2. **Matched construction.**

For every matched pair `(R,W)`, the kernel above is one-dimensional. This is proved in:

```text
docs/rfc_distance_analysis/rfc_matched_kernel_induction.md
```

3. **No early gluing.**

In the two-child equality branch, if the common child output support has size greater than one,
then simultaneous cancellation would impose two or more independent parent-challenge ratio
conditions using only one child-line scalar. This is impossible over the rational function field.
This local lemma is isolated in:

```text
docs/rfc_distance_analysis/rfc_no_early_gluing_lemma.md
```

## Classification Proof

Assume there is a nonzero vector:

```text
x supported in R
supp(A_d x) subset W
```

with `|R||W|=k`.

Since `x` is supported in `R` and `A_d x` is supported in `W`:

```text
wt(x) <= |R|
wt(A_d x) <= |W| = k/|R|.
```

By uncertainty:

```text
wt(A_d x) >= k/wt(x).
```

If `wt(x) < |R|`, then:

```text
wt(A_d x) >= k/wt(x) > k/|R| = |W|,
```

contradicting `supp(A_d x) subset W`.

Therefore both are equal:

```text
wt(x) = |R|
wt(A_d x) = |W|.
```

So `x` is an exact uncertainty extremizer, using every row in `R` and every output in `W`.

Now split at the root:

```text
x = (x_0,x_1)
u = A_{d-1} x_0
v = A_{d-1} x_1.
```

Equality in the uncertainty proof gives two possible branches.

## One-Child Branch

If exactly one of `x_0,x_1` is nonzero, then that child is itself an exact extremizer. The parent
output support is exactly both sibling lifts of the child output support.

Consequences:

```text
R lies in one child;
W is both sibling lifts of a child support W';
(R_child, W') satisfies the same exact-boundary equation.
```

By induction, `(R_child,W')` is matched. Lifting preserves:

```text
R = row block of size m,
W = stride class modulo m.
```

This is the descent phase.

## Two-Child Branch

If both children are nonzero, equality forces:

```text
wt(x_0)=wt(x_1)=|R|/2,
supp(u)=supp(v)=W',
```

and each coordinate in `W'` has exactly one surviving parent sibling.

By no early gluing, this branch is impossible unless:

```text
|W'| = 1.
```

At the node where this branch occurs, the local exact-boundary relation is:

```text
|R_node| |W_node| = node_size.
```

In the two-child branch, `|W_node|=|W'|`. If `|W'|=1`, then:

```text
|R_node| = node_size.
```

So the live support fills the current node. The two child live supports are the two full sibling
halves of that node. The selected surviving sibling over the single child output coordinate chooses
one output bit. Recursing downward through the full node chooses the remaining output bits.

Thus the two-child branch produces exactly the glue phase of the matched construction:

```text
R is the full current block,
W is one residue class modulo |R|.
```

## Conclusion

The equality recursion consists of:

```text
1. zero or more one-child descent steps;
2. a full-node glue recursion.
```

Therefore every exact extremizer has matched block/stride support. The matched construction gives
one-dimensional kernels for these pairs, and uncertainty rules out non-matched kernels.

This proves the exact-boundary statement using the local no-early-gluing rational-function lemma.
